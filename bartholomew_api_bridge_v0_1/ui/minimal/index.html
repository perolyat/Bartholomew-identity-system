What do these scopes stop?
Ticking no box and pressing Engage applies the brake globally. Ticking boxes restricts it to those areas only.
  • global — everything below, together.
  • skills — Bartholomew stops running skills/tools.
  • sight — visual input paths.
  • voice — voice input/output paths.
  • scheduler — his own background activity stops.
  • training — no new material is taken in.

The brake is enforced in Governance, not here. This panel reads and sets it; if the reading cannot be taken it says UNKNOWN rather than showing “disengaged”.
